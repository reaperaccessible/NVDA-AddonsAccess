BookmarksAccess

BookmarksAccess rassemble vos favoris de Chrome, Edge, Brave et Firefox dans une liste qui lui est propre. Vous rangez cette liste en dossiers, dans une fenêtre faite pour NVDA.

BookmarksAccess lit seulement les favoris de vos navigateurs : il ne les change jamais. Ce que vous faites dans sa liste reste dans sa liste.

Raccourci clavier

  • NVDA+Contrôle+Maj+U : dans Chrome, Edge, Brave ou Firefox, ajoute à votre liste la page que vous lisez. Dans tout autre programme, NVDA dit « Pas dans un navigateur web. ».

Pour ouvrir la fenêtre de vos favoris, allez dans le menu NVDA, Outils, BookmarksAccess. Vous pouvez aussi lui donner votre propre raccourci : menu NVDA, Préférences, Gestes de commandes, catégorie BookmarksAccess, « Ouvre BookmarksAccess, votre liste de favoris ». Vous pouvez changer NVDA+Contrôle+Maj+U au même endroit.

Ajouter la page que vous lisez

  1. Dans votre navigateur web, ouvrez la page.
  2. Appuyez sur NVDA+Contrôle+Maj+U. NVDA dit « Adresse copiée » : l'adresse de la page est maintenant dans le presse-papiers, prête à être collée.
  3. La fenêtre Ajouter s'ouvre. Le nom et l'adresse de la page sont déjà remplis, et vous êtes dans la liste des dossiers. Choisissez le dossier avec les flèches, puis appuyez sur Entrée.

La page est ajoutée, et la fenêtre de vos favoris la montre. La fois suivante, la liste des dossiers commence sur le dernier dossier choisi.

Le bouton « Nouveau dossier » de la fenêtre Ajouter crée tout de suite un dossier pour la page.

Si la page est déjà dans votre liste, NVDA dit « Adresse copiée. Déjà dans vos favoris. », et la fenêtre montre où elle se trouve.

L'adresse est lue dans la page elle-même : la barre d'adresse n'est pas touchée. Si vous n'êtes pas dans la page, par exemple dans la barre d'adresse, BookmarksAccess prend la page affichée dans la fenêtre. S'il n'en trouve aucune, NVDA dit « Aucune page web trouvée. Allez d'abord dans la page. ».

La fenêtre de vos favoris

La fenêtre montre une arborescence : vos dossiers, et dedans, vos adresses. Déplacez-vous avec les flèches haut et bas. La flèche droite ouvre un dossier, la flèche gauche le ferme. Sur le premier élément, la flèche haut dit « Premier, » suivi de son nom ; sur le dernier, la flèche bas dit « Dernier, ». Un dossier sans rien dedans dit « vide » après son nom.

La touche Applications, ou Maj+F10, montre les commandes avec leurs touches. Chaque commande marche aussi avec sa touche, directement dans l'arborescence :

  • Ouvrir dans le navigateur (Entrée) : ouvre l'adresse dans votre navigateur web par défaut. Sur un dossier, Entrée l'ouvre ou le ferme.
  • Ajouter une adresse (Contrôle+N) : tapez le nom et l'adresse, puis choisissez le dossier. L'adresse va dans le dossier sélectionné, ou dans le dossier de l'adresse sélectionnée.
  • Nouveau dossier (Contrôle+Maj+N) : crée un dossier dans le dossier sélectionné.
  • Renommer (F2) : change le nom d'un dossier ou d'une adresse.
  • Modifier l'adresse (Contrôle+E) : change l'adresse d'une page web.
  • Déplacer dans un dossier (Contrôle+M) : montre la liste de vos dossiers ; choisissez où va l'élément, puis appuyez sur Entrée. Un dossier se déplace avec tout ce qu'il contient.
  • Sélectionner aussi l'élément suivant (Maj+Flèche bas) : sélectionne l'élément où vous êtes et le suivant, puis va sur le suivant. Appuyez de nouveau pour en ajouter d'autres. Couper, Déplacer dans un dossier et Supprimer agissent alors sur tous les éléments sélectionnés. Se déplacer avec les flèches seules termine la sélection.
  • Sélectionner aussi l'élément précédent (Maj+Flèche haut) : la même chose, vers le haut.
  • Couper (Contrôle+X) : prend les éléments sélectionnés, ou l'élément où vous êtes. Ils restent à leur place jusqu'à ce que vous les colliez.
  • Coller dans ce dossier (Contrôle+V) : déplace les éléments coupés dans le dossier sélectionné, ou dans le dossier de l'adresse sélectionnée.
  • Copier l'adresse (Contrôle+C) : copie l'adresse dans le presse-papiers.
  • Supprimer (Suppr) : demande d'abord, puis supprime. Supprimer un dossier supprime tout ce qu'il contient.
  • Trier par (Alt+T) : va dans la liste Trier par.
  • Importer des navigateurs (Contrôle+I) : voir la section suivante.
  • Liste des touches (Contrôle+Maj+H) : montre toutes ces touches. F1 la montre aussi.
  • Fermer (Échap) : ferme la fenêtre.

Les boutons du bas de la fenêtre font les commandes les plus courantes : Ouvrir, Ajouter une adresse, Importer des navigateurs et Fermer.

« Haut de la liste », dans les listes de dossiers, veut dire en dehors de tout dossier.

La liste « Trier par », juste avant l'arborescence, range chaque dossier : Mon ordre, Nom de A à Z, Nom de Z à A, Date d'ajout (les plus récentes ou les plus anciennes d'abord), ou Les plus ouvertes d'abord, qui compte les adresses ouvertes depuis BookmarksAccess. Dans chaque dossier, les dossiers viennent toujours en premier. Le tri change seulement ce que vous voyez : en revenant à « Mon ordre », vous retrouvez votre rangement tel que vous l'avez laissé. L'extension se souvient de votre choix.

Importer vos favoris

La première fois que vous ouvrez la fenêtre, votre liste est vide : BookmarksAccess demande s'il faut importer les favoris de vos navigateurs web. Vous pouvez importer de nouveau à tout moment avec Contrôle+I.

BookmarksAccess cherche les favoris de Chrome, Edge, Brave et Firefox, dans chaque profil. Chaque navigateur a son propre dossier, par exemple « Chrome » ou « Firefox », et ses dossiers sont gardés dedans : barre de favoris, autres favoris, et vos propres dossiers. Si un navigateur a plusieurs profils, chacun a son dossier, avec le nom du profil.

À la fin, NVDA dit combien d'adresses ont été ajoutées, par exemple « 120 nouvelles adresses, de Chrome, Firefox. ».

Importer de nouveau ajoute seulement les nouvelles adresses :

  • une adresse déjà dans votre liste n'est jamais ajoutée deux fois, même si elle est dans plusieurs navigateurs ;
  • ce que vous avez renommé ou déplacé reste comme vous l'avez laissé ; une nouvelle adresse va dans son dossier, même si vous avez renommé ou déplacé ce dossier ;
  • une adresse que vous avez supprimée ne revient pas.

Pour Firefox, BookmarksAccess lit la copie des favoris que Firefox enregistre de lui-même, en général une fois par jour quand vous vous en servez. Un favori ajouté aujourd'hui dans Firefox peut donc n'arriver qu'à une importation suivante.

Chaque adresse garde la date où vous l'avez ajoutée dans le navigateur. Une adresse déjà dans votre liste reçoit cette date au prochain import. Si vous supprimez tout, le prochain import remet toutes les adresses, même celles que vous aviez supprimées.

Réglages

Les réglages sont dans le menu NVDA, Préférences, Paramètres, catégorie BookmarksAccess :

  • Vérifier automatiquement les mises à jour au démarrage de NVDA et Vérifier les mises à jour maintenant : voir la section suivante.
  • Options avancées... : une seule option, « Copier l'adresse dans le presse-papiers en ajoutant la page affichée », cochée au départ. Décochée, NVDA+Contrôle+Maj+U ajoute la page sans toucher au presse-papiers.

Mises à jour

Au démarrage de NVDA, BookmarksAccess regarde si une nouvelle version existe. Si oui, il propose de l'installer, puis de redémarrer NVDA. Le bouton « Vérifier les mises à jour maintenant » fait tout de suite la même vérification.

Où est gardée votre liste

Votre liste est un fichier nommé bookmarksAccess.json, dans le dossier de configuration de NVDA, avec une copie de son état précédent nommée bookmarksAccess.json.bak. Elle est enregistrée après chaque changement.

Confidentialité

Vos favoris restent sur votre ordinateur : rien n'est envoyé sur Internet. La seule connexion de l'extension à Internet est la vérification des mises à jour.
