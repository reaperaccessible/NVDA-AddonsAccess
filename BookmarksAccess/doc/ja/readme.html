BookmarksAccess

BookmarksAccess は、Chrome、Edge、Brave、Firefox のブックマークを、専用の 1 つのリストにまとめます。このリストは、NVDA のために作られたウィンドウで、フォルダーに整理できます。

BookmarksAccess は、ブラウザーのブックマークを読み取るだけで、変更することはありません。リストの中で行った操作は、リストの中だけに残ります。

キーボードショートカット

  • NVDA+Control+Shift+U: Chrome、Edge、Brave、Firefox で、読んでいるページをリストに追加します。ほかのプログラムでは、NVDA が「Web ブラウザーではありません。」と話します。

ブックマークのウィンドウを開くには、NVDA メニューの「ツール」から BookmarksAccess を選びます。自分のショートカットを割り当てることもできます。NVDA メニュー、設定、入力ジェスチャー、BookmarksAccess のカテゴリーで、「BookmarksAccess、ブックマークのリストを開きます」を選びます。NVDA+Control+Shift+U も同じ場所で変更できます。

読んでいるページを追加する

  1. Web ブラウザーで、ページを開きます。
  2. NVDA+Control+Shift+U を押します。NVDA が「アドレスをコピーしました」と話します。ページのアドレスがクリップボードに入り、貼り付けられる状態になります。
  3. 「追加」ウィンドウが開きます。ページの名前とアドレスはすでに入力されていて、フォルダーのリストにいます。矢印キーでフォルダーを選び、Enter を押します。

ページが追加され、ブックマークのウィンドウに表示されます。次回は、前回選んだフォルダーからフォルダーのリストが始まります。

「追加」ウィンドウの「新しいフォルダー」ボタンを押すと、そのページのためのフォルダーをすぐに作れます。

ページがすでにリストにある場合、NVDA は「アドレスをコピーしました。すでにブックマークにあります。」と話し、ウィンドウにその場所が表示されます。

アドレスはページ自体から読み取られ、アドレスバーには触れません。フォーカスがページになく、たとえばアドレスバーにあるときは、BookmarksAccess はウィンドウに表示されているページを使います。見つからない場合、NVDA は「Web ページが見つかりません。先にページへ移動してください。」と話します。

ブックマークのウィンドウ

ウィンドウにはツリーが表示されます。フォルダーと、その中のアドレスです。上矢印と下矢印で移動します。右矢印でフォルダーを開き、左矢印で閉じます。最初の項目で上矢印を押すと、「先頭、」に続けて名前を話します。最後の項目で下矢印を押すと、「末尾、」と話します。中に何もないフォルダーは、名前の後に「空」と話します。

アプリケーションキーまたは Shift+F10 を押すと、コマンドとそのキーが表示されます。各コマンドは、ツリーの上から、そのキーでも使えます。

  • ブラウザーで開く (Enter): 既定の Web ブラウザーでアドレスを開きます。フォルダーでは、Enter で開閉します。
  • アドレスを追加 (Control+N): 名前とアドレスを入力し、フォルダーを選びます。アドレスは、選択中のフォルダー、または選択中のアドレスがあるフォルダーに入ります。
  • 新しいフォルダー (Control+Shift+N): 選択中のフォルダーの中に、フォルダーを作ります。
  • 名前の変更 (F2): フォルダーまたはアドレスの名前を変えます。
  • アドレスの変更 (Control+E): Web ページのアドレスを変えます。
  • フォルダーへ移動 (Control+M): フォルダーのリストを表示します。項目の移動先を選び、Enter を押します。フォルダーは、中身ごと移動します。
  • 次の項目も選択 (Shift+下矢印): 今いる項目と次の項目を選択し、次の項目へ移ります。もう一度押すと、さらに追加できます。切り取り、フォルダーへ移動、削除は、選択したすべての項目に働きます。矢印キーだけで移動すると、選択は終わります。
  • 前の項目も選択 (Shift+上矢印): 同じことを上に向かって行います。
  • 切り取り (Control+X): 選択した項目、または今いる項目を取ります。貼り付けるまで、項目は元の場所に残ります。
  • このフォルダーに貼り付け (Control+V): 切り取った項目を、選択したフォルダー、または選択したアドレスのフォルダーへ移動します。
  • アドレスをコピー (Control+C): アドレスをクリップボードにコピーします。
  • 削除 (Delete): 先に確認してから削除します。フォルダーを削除すると、中のものもすべて削除されます。
  • 並べ替え (Alt+S): 「並べ替え」のリストへ移ります。
  • ブラウザーからインポート (Control+I): 次の項目を見てください。
  • キーの一覧 (Control+Shift+H): これらのキーをすべて表示します。F1 でも表示できます。
  • 閉じる (Escape): ウィンドウを閉じます。

ウィンドウの下にあるボタンで、よく使うコマンドを実行できます。開く、アドレスを追加、ブラウザーからインポート、閉じる、です。

フォルダーのリストにある「リストの先頭」は、どのフォルダーにも入っていないという意味です。

ツリーのすぐ前にある「並べ替え」のリストで、各フォルダーを並べ替えます: 自分の順番、名前 (A から Z)、名前 (Z から A)、追加日 (新しい順または古い順)、または BookmarksAccess から開いた回数で並べる、よく開く順。どのフォルダーでも、フォルダーが常に先に来ます。並べ替えは見え方を変えるだけです。「自分の順番」に戻すと、自分で並べたとおりに戻ります。アドオンは選んだ並べ方を覚えています。

ブックマークをインポートする

ウィンドウを初めて開くとリストは空で、BookmarksAccess が、Web ブラウザーのブックマークをインポートするかどうかを尋ねます。インポートは、いつでも Control+I でやり直せます。

BookmarksAccess は、Chrome、Edge、Brave、Firefox のブックマークを、すべてのプロフィールから探します。ブラウザーごとに「Chrome」や「Firefox」のような専用のフォルダーができ、その中にブラウザーのフォルダー、つまりブックマークバー、その他のブックマーク、自分で作ったフォルダーがそのまま残ります。ブラウザーに複数のプロフィールがある場合は、プロフィールの名前がついたフォルダーがそれぞれできます。

最後に、NVDA が追加されたアドレスの数を話します。たとえば「新しいアドレス 120 件、Chrome, Firefox から。」です。

もう一度インポートすると、新しいアドレスだけが追加されます。

  • すでにリストにあるアドレスは、複数のブラウザーにあっても、2 回追加されることはありません。
  • 名前を変えたものや移動したものは、そのままです。新しいアドレスは、そのフォルダーの名前を変えたり移動したりしていても、そのフォルダーに入ります。
  • 削除したアドレスは、戻ってきません。

Firefox では、Firefox が自動で保存するブックマークのコピーを読み取ります。コピーは、使っているときに通常 1 日に 1 回保存されます。そのため、今日 Firefox に追加したブックマークは、あとのインポートで届くことがあります。

各アドレスは、ブラウザーでブックマークした日付を保ちます。すでにリストにあるアドレスは、次のインポートでその日付になります。 すべて削除した場合、次のインポートで、削除したものも含めてすべてのアドレスが戻ります。

設定

設定は、NVDA メニュー、設定、設定の中の BookmarksAccess のカテゴリーにあります。

  • NVDA の起動時に自動的に更新を確認すると今すぐ更新を確認: 次の項目を見てください。
  • 詳細オプション...: オプションは 1 つだけで、「表示中のページを追加するときにアドレスをクリップボードにコピーする」です。初めはチェックされています。チェックを外すと、NVDA+Control+Shift+U は、クリップボードを変えずにページを追加します。

更新

NVDA が起動すると、BookmarksAccess は新しいバージョンがあるかどうかを確認します。ある場合は、インストールするかどうかを尋ね、続いて NVDA を再起動するかどうかを尋ねます。「今すぐ更新を確認」ボタンは、同じ確認をその場で行います。

リストの保存場所

リストは、NVDA の設定フォルダーにある bookmarksAccess.json というファイルです。1 つ前の状態のコピーが bookmarksAccess.json.bak という名前で残ります。変更するたびに保存されます。

プライバシー

ブックマークはお使いのコンピューターの中にとどまり、インターネットには何も送られません。このアドオンがインターネットに接続するのは、更新の確認のときだけです。
