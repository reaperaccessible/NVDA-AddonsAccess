BookmarksAccess

BookmarksAccess gathers your bookmarks from Chrome, Edge, Brave and Firefox in one list of its own. You organise this list in folders, in a window made for NVDA.

BookmarksAccess only reads your browsers' bookmarks: it never changes them. What you do in its list stays in its list.

Keyboard shortcut

  • NVDA+Control+Shift+U: in Chrome, Edge, Brave or Firefox, adds the page you are reading to your list. In any other program, NVDA says "Not in a web browser."

To open the window of your bookmarks, go to the NVDA menu, Tools, BookmarksAccess. You can also give it a shortcut of your own: NVDA menu, Preferences, Input gestures, category BookmarksAccess, "Opens BookmarksAccess, your list of bookmarks". You can change NVDA+Control+Shift+U in the same place.

Add the page you are reading

  1. In your web browser, open the page.
  2. Press NVDA+Control+Shift+U. NVDA says "Address copied": the address of the page is now in the clipboard, ready to be pasted.
  3. The Add window opens. The name and the address of the page are already filled in, and you are in the list of folders. Choose the folder with the arrows, then press Enter.

The page is added, and the window of your bookmarks shows it. The next time, the list of folders starts on the folder you chose last.

The "New folder" button of the Add window makes a folder for the page right away.

If the page is already in your list, NVDA says "Address copied. Already in your bookmarks." and the window shows where it is.

The address is read from the page itself: the address bar is not touched. If the focus is not in the page, for example in the address bar, BookmarksAccess takes the page shown in the window. If it finds none, NVDA says "No web page found. Move to the page first."

The window of your bookmarks

The window shows a tree: your folders, and inside them, your addresses. Move with the up and down arrows. The right arrow opens a folder, the left arrow closes it. On the first item, the up arrow says "First," followed by its name; on the last item, the down arrow says "Last,". A folder with nothing inside says "empty" after its name.

The Applications key, or Shift+F10, shows the commands with their keys. Each command also works with its key, straight from the tree:

  • Open in the browser (Enter): opens the address in your default web browser. On a folder, Enter opens or closes it.
  • Add an address (Control+N): type the name and the address, then choose the folder. The address goes into the selected folder, or into the folder of the selected address.
  • New folder (Control+Shift+N): makes a folder inside the selected folder.
  • Rename (F2): changes the name of a folder or of an address.
  • Edit the address (Control+E): changes the address of a web page.
  • Move to a folder (Control+M): shows the list of your folders; choose where the item goes, then press Enter. A folder moves with everything inside it.
  • Select the next item too (Shift+Down arrow): selects the item where you are and the next one, then goes there. Press it again to add more. Cut, Move to a folder and Delete then act on all the selected items. Moving with the arrows alone ends the selection.
  • Select the previous item too (Shift+Up arrow): the same, upward.
  • Cut (Control+X): takes the selected items, or the item where you are. They stay where they are until you paste them.
  • Paste into this folder (Control+V): moves the items you cut into the selected folder, or into the folder of the selected address.
  • Copy the address (Control+C): copies the address to the clipboard.
  • Delete (Del): asks first, then deletes. Deleting a folder deletes everything inside it.
  • Sort by (Alt+S): goes to the list Sort by.
  • Import from the browsers (Control+I): see the next section.
  • List of keys (Control+Shift+H): shows all these keys. F1 shows it too.
  • Close (Escape): closes the window.

The buttons at the bottom of the window do the most common commands: Open, Add an address, Import from the browsers and Close.

"Top of the list", in the lists of folders, means outside any folder.

The list Sort by, just before the tree, puts each folder in order: My order, Name from A to Z, Name from Z to A, Date added (newest or oldest first), or Most opened first, which counts the addresses opened from BookmarksAccess. In each folder, the folders always come first. Sorting only changes what you see: back to My order, your own arrangement is there as you left it. The add-on remembers your choice.

Import your bookmarks

The first time you open the window, your list is empty: BookmarksAccess asks whether to import the bookmarks of your web browsers. You can import again at any time with Control+I.

BookmarksAccess looks for the bookmarks of Chrome, Edge, Brave and Firefox, in every profile. Each browser gets its own folder, such as "Chrome" or "Firefox", and its folders are kept inside it: bookmarks bar, other bookmarks, and your own folders. If a browser has several profiles, each gets its folder, with the name of the profile.

At the end, NVDA says how many addresses were added, for example "120 new addresses, from Chrome, Firefox."

Importing again adds only the new addresses:

  • an address already in your list is never added twice, even if it is in several browsers;
  • what you renamed or moved stays as you left it; a new address goes into its folder, even if you renamed or moved that folder;
  • an address you deleted does not come back.

For Firefox, BookmarksAccess reads the copy of the bookmarks that Firefox saves by itself, usually once a day when you use it. A bookmark added in Firefox today may therefore arrive at a later import.

Each address keeps the date when you bookmarked it in the browser. An address already in your list gets that date at the next import. If you delete everything, the next import brings back every address, even the ones you had deleted.

Settings

The settings are in the NVDA menu, Preferences, Settings, category BookmarksAccess:

  • Check for updates automatically when NVDA starts and Check for updates now: see the next section.
  • Advanced options...: one option, "Copy the address to the clipboard when adding the current page", checked by default. Unchecked, NVDA+Control+Shift+U adds the page without changing the clipboard.

Updates

When NVDA starts, BookmarksAccess checks whether a new version exists. If one does, it offers to install it, then to restart NVDA. The "Check for updates now" button does the same check right away.

Where your list is kept

Your list is a file named bookmarksAccess.json, in NVDA's configuration folder, with a copy of its previous state named bookmarksAccess.json.bak. It is saved after each change.

Privacy

Your bookmarks stay on your computer: nothing is sent over the Internet. The add-on's only connection to the Internet is the update check.
