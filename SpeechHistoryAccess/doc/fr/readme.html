SpeechHistoryAccess

SpeechHistoryAccess garde en mémoire ce que NVDA vient d'annoncer. Vous pouvez relire les annonces précédentes, les copier dans le presse-papiers, en enregistrer plusieurs d'un coup, ou afficher tout l'historique dans une fenêtre.

L'extension s'affiche en français lorsque NVDA est en français, et en anglais dans toutes les autres langues.

Raccourcis clavier

  • NVDA+Ctrl+Maj+F10 : lire l'élément précédent de l'historique, c'est-à-dire une annonce plus ancienne.
  • NVDA+Ctrl+Maj+F11 : lire l'élément suivant de l'historique, c'est-à-dire une annonce plus récente.
  • NVDA+Ctrl+Maj+F12 : copier dans le presse-papiers l'élément sélectionné. Si vous n'avez pas parcouru l'historique, c'est la dernière annonce de NVDA.
  • NVDA+Ctrl+Maj+F9 : démarrer l'enregistrement de la parole.
  • NVDA+Ctrl+Maj+F8 : arrêter l'enregistrement et copier dans le presse-papiers tout ce qui a été annoncé entre-temps.
  • NVDA+Ctrl+Maj+H : afficher tout l'historique dans une fenêtre que vous parcourez avec les flèches.

Un bip grave indique que vous avez atteint le début ou la fin de l'historique.

Modifier les raccourcis

Ouvrez le menu NVDA, Préférences, Gestes de commandes. Les six commandes de l'extension se trouvent dans la rubrique « SpeechHistoryAccess ». Vous pouvez y changer ou retirer chaque raccourci.

Relire et copier une annonce

  1. Appuyez sur NVDA+Ctrl+Maj+F10 autant de fois que nécessaire pour remonter jusqu'à l'annonce voulue.
  2. Appuyez sur NVDA+Ctrl+Maj+F12 pour la copier.
  3. Collez-la où vous voulez avec Ctrl+V.

Dès que NVDA annonce quelque chose de nouveau, la sélection revient sur l'annonce la plus récente.

Enregistrer plusieurs annonces

  1. Appuyez sur NVDA+Ctrl+Maj+F9. NVDA annonce « Enregistrement de la parole démarré ».
  2. Faites ce que vous voulez capturer : lire un texte, parcourir une fenêtre, etc.
  3. Appuyez sur NVDA+Ctrl+Maj+F8. Toutes les annonces faites entre-temps sont copiées dans le presse-papiers, une par ligne.

Réglages

Ouvrez le menu NVDA, Préférences, Paramètres, puis la catégorie « SpeechHistoryAccess ».

  • Nombre maximal d'entrées dans l'historique : 500 par défaut. Le changement prend effet au redémarrage de NVDA.
  • Après la copie : ce que fait NVDA pour confirmer une copie. Les choix sont Ne rien faire, Bip, Annoncer, ou Bip et annonce. Le réglage par défaut est Bip.
  • Fréquence du bip : 1500 Hz par défaut.
  • Durée du bip : 120 millisecondes par défaut.
  • Jouer un bip d'exemple : ce bouton fait entendre le bip avec la fréquence et la durée choisies.
  • Supprimer les espaces au début du texte copié : décochée par défaut.
  • Supprimer les espaces à la fin du texte copié : décochée par défaut.
  • Vérifier automatiquement les mises à jour au démarrage de NVDA : cochée par défaut.
  • Vérifier les mises à jour maintenant : ce bouton lance la vérification tout de suite.

Les réglages du bip ne sont disponibles que si « Après la copie » utilise un bip.

Mises à jour

SpeechHistoryAccess ne passe pas par l'Add-on Store de NVDA. L'extension vérifie elle-même, peu après le démarrage de NVDA, si une nouvelle version est publiée. Si c'est le cas, une fenêtre vous propose de l'installer, puis de redémarrer NVDA.

Cette vérification contacte uniquement GitHub. Pour la désactiver, décochez la case correspondante dans les réglages ; vous pourrez toujours vérifier à la main avec le bouton.

Dans l'Add-on Store, l'extension apparaît avec le canal « Externe ». C'est normal pour une extension installée en dehors du Store.

Confidentialité

L'historique reste dans la mémoire de NVDA. Il n'est écrit dans aucun fichier et il est effacé à la fermeture de NVDA.
