SpeechHistoryAccess

SpeechHistoryAccess remembers what NVDA has just said. You can review earlier announcements, copy them to the clipboard, record several of them at once, or show the whole history in a window.

The add-on is displayed in French when NVDA is in French, and in English in every other language.

Keyboard shortcuts

  • NVDA+Shift+F10: review the previous item in the history, that is, an older announcement.
  • NVDA+Shift+F11: review the next item in the history, that is, a more recent announcement.
  • NVDA+Shift+F12: copy the selected item to the clipboard. If you have not moved through the history, this is NVDA's last announcement.
  • NVDA+Shift+F9: start recording speech.
  • NVDA+Shift+F8: stop recording and copy everything announced in the meantime to the clipboard.
  • NVDA+H: show the whole history in a window that you read with the arrow keys.

A low beep tells you that you have reached the start or the end of the history.

Note: NVDA+Shift+F9 is also an NVDA command, which moves the review cursor back to the start marker for copying. While the add-on is enabled, this shortcut starts recording instead.

Changing the shortcuts

Open the NVDA menu, Preferences, Input gestures. The add-on's six commands are in the "SpeechHistoryAccess" category. You can change or remove each shortcut there.

Reviewing and copying an announcement

  1. Press NVDA+Shift+F10 as many times as needed to go back to the announcement you want.
  2. Press NVDA+Shift+F12 to copy it.
  3. Paste it wherever you like with Ctrl+V.

As soon as NVDA says something new, the selection returns to the most recent announcement.

Recording several announcements

  1. Press NVDA+Shift+F9. NVDA says "Started recording speech".
  2. Do whatever you want to capture: read a text, explore a window, and so on.
  3. Press NVDA+Shift+F8. Every announcement made in the meantime is copied to the clipboard, one per line.

Settings

Open the NVDA menu, Preferences, Settings, then the "SpeechHistoryAccess" category.

  • Maximum number of history entries: 500 by default. The change takes effect when NVDA restarts.
  • After copying speech: what NVDA does to confirm a copy. The choices are Do nothing, Beep, Speak, or Both beep and speak. The default is Beep.
  • Beep frequency: 1500 Hz by default.
  • Beep duration: 120 milliseconds by default.
  • Play example beep: this button plays the beep with the chosen frequency and duration.
  • Trim whitespace from start when copying text: unchecked by default.
  • Trim whitespace from end when copying text: unchecked by default.
  • Check for updates automatically when NVDA starts: checked by default.
  • Check for updates now: this button starts the check right away.

The beep settings are only available when "After copying speech" uses a beep.

Updates

SpeechHistoryAccess does not go through NVDA's Add-on Store. The add-on checks by itself, shortly after NVDA starts, whether a new version has been published. If so, a window offers to install it, then to restart NVDA.

This check contacts GitHub only. To turn it off, uncheck the corresponding box in the settings; you can still check by hand with the button.

In the Add-on Store, the add-on is listed with the "External" channel. This is normal for an add-on installed from outside the Store.

Privacy

The history stays in NVDA's memory. It is not written to any file and it is cleared when NVDA exits.
