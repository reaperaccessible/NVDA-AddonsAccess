KeyboardAccess

KeyboardAccess brings together three keyboard tools:

  • it gives back the Applications key, the key that opens the context menu, to keyboards that do not have one, especially on laptops;
  • it clicks the selected item, with the left or right mouse button, or double-clicks it;
  • it changes the keyboard language among all those Windows knows, without having to add them in Windows' settings.

The add-on is displayed in French when NVDA is in French, and in English in every other language.

The keyboard window

NVDA+Ctrl+Shift+K opens the window, also found in the NVDA menu, Tools. It holds two lists: the actions, each with its key, then the keyboard languages. Tab moves from one to the other.

The list of actions:

  • Applications key: opens the context menu of the selected item. As on a real keyboard, Shift with this key opens the extended context menu, which offers more choices (on Windows 11, it gives the former full menu).
  • Left click: clicks the selected item.
  • Double click: double-clicks the selected item, for example to open an item when Enter does not work.
  • Right click: right-clicks the selected item.
  • Switch keyboard: switches between your keyboard and the last keyboard language chosen in the window (see below).

At first, no action has a key.

Assigning a key

  1. Choose the action in the list with the arrow keys.
  2. Press Enter, or the "Assign a key" button.
  3. NVDA says "Press the key to use…". Press the key you want, for example Print Screen.
  4. NVDA confirms, for example "print screen is now the Applications key. With Shift, it opens the extended menu." That is all: the key works right away, in all your programs.

Escape cancels the waiting. Keys used to type or to move around, pressed alone (a letter, a digit, Enter, Tab, Space, the arrows…), are refused: NVDA then asks you to choose another one.

For the Applications key, only a key alone is accepted, without Ctrl, Alt, Shift or NVDA: this is what lets Shift with this key open the extended menu. The keys alone that suit best are AltGr (Right Alt), Right Ctrl, Print Screen, Pause and Scroll Lock.

With AltGr or Right Ctrl, the Applications key works when you press and release the key with nothing else. Used with another key, it keeps its usual role: AltGr+2 still types @, for example. If you hold it down for more than a second, nothing happens. When NVDA controls another computer with the Remote, the Applications key is sent to that other computer, with Shift too. For the clicks, you may also choose a combination, for example Ctrl+Alt+K.

If the key is already used by another command of NVDA or of an add-on, NVDA tells you and asks whether you want to use it anyway. Each action has a single key: assigning a new one replaces the old one.

Removing a key

Choose the action, then press Delete, or the "Remove the key" button.

The sound of the clicks

The "Play a sound for each click" check box plays a small confirmation click. It is checked by default.

The keyboard language

The "Keyboard language" list starts with your keyboard, for example "Your keyboard: French (Canada)", then gives every keyboard layout of Windows, more than two hundred, in alphabetical order. Type the first letter of a name to go straight to it. The layout in use is followed by "(in use)".

Enter on a language turns it on at once in all your programs, and NVDA confirms, for example "Keyboard: English (United States)". Everything works exactly as if you had added it in Windows' settings, combinations such as Ctrl+Z and dead keys included, because it really is Windows' layout that is used. Nothing is downloaded.

Enter on "Your keyboard" brings you back to your keyboard. The languages the add-on had added are then removed from Windows. Those you had added yourself in Windows' settings stay.

The "Switch keyboard" action, in the list of actions, switches with a single key from your keyboard to the last language chosen, and back. Give it a key to go back and forth without opening the window.

Escape or the "Close" button close the window. Close it, then use your keys and your keyboard in your programs.

Good to know

  • The keys assigned are saved in NVDA's input gestures. You also find them in the NVDA menu, Preferences, Input gestures, "KeyboardAccess" category.
  • If you assign a combination with Ctrl, Alt or Shift to a click, the add-on waits until you release these keys before clicking.
  • The Applications key and Shift with it also appear separately in NVDA's Input gestures, except AltGr and Right Ctrl, which NVDA cannot assign alone: the add-on watches them itself.
  • If a program such as SharpKeys has already remapped a key in Windows, remove that remapping first.
  • To click, the add-on puts the mouse pointer on the selected item. If the item is not visible on the screen, NVDA says so and does not click.
  • In most programs, Shift+F10 also opens the context menu, without any add-on.
  • Your keyboard is the one you were using the first time you changed language with the add-on.
  • While a language added by the add-on is in use, it also appears in Windows' language switcher (Windows+Space). It disappears from it when you go back to your keyboard.
  • The change of language follows Windows' setting: by default, the same keyboard language applies to every program.

Settings

In the NVDA menu, Preferences, Settings, "KeyboardAccess" category:

  • Play a sound for each click: checked by default.
  • Check for updates automatically when NVDA starts: checked by default.
  • Check for updates now: starts the check right away.

Updates

KeyboardAccess does not go through NVDA's Add-on Store. The add-on checks by itself, shortly after NVDA starts, whether a new version has been published, and offers to install it. When several ReaperAccessible add-ons are updated together, their windows open one after the other and NVDA asks to restart only once.

In the Add-on Store, the add-on is listed with the "External" channel. This is normal for an add-on installed from outside the Store.

Privacy

The add-on only contacts the Internet to check for updates, with GitHub.
