KeyboardAccess

KeyboardAccess rassemble trois outils pour le clavier :

  • il redonne la touche Applications, celle qui ouvre le menu contextuel, aux claviers qui n'en ont pas, surtout sur les ordinateurs portables ;
  • il clique sur l'élément sélectionné, avec le bouton gauche ou droit de la souris, ou double-clique ;
  • il change la langue du clavier parmi toutes celles que Windows connaît, sans avoir à les ajouter dans les paramètres de Windows.

L'extension s'affiche en français lorsque NVDA est en français, et en anglais dans toutes les autres langues.

La fenêtre du clavier

NVDA+Ctrl+Maj+K ouvre la fenêtre, que l'on trouve aussi dans le menu NVDA, Outils. Elle contient deux listes : les actions, chacune avec sa touche, puis les langues du clavier. Tab passe de l'une à l'autre.

La liste des actions :

  • Touche Applications : ouvre le menu contextuel de l'élément sélectionné. Comme sur un vrai clavier, Maj avec cette touche ouvre le menu contextuel étendu, qui propose plus de choix (sous Windows 11, c'est lui qui donne l'ancien menu complet).
  • Clic gauche : clique sur l'élément sélectionné.
  • Double-clic : double-clique sur l'élément sélectionné, par exemple pour ouvrir un élément quand Entrée ne fonctionne pas.
  • Clic droit : fait un clic droit sur l'élément sélectionné.
  • Changer de clavier : passe de votre clavier à la dernière langue de clavier choisie dans la fenêtre, et inversement (voir plus bas).

Au départ, aucune action n'a de touche.

Assigner une touche

  1. Choisissez l'action dans la liste avec les flèches.
  2. Appuyez sur Entrée, ou sur le bouton « Assigner une touche ».
  3. NVDA dit « Appuyez sur la touche à utiliser… ». Appuyez sur la touche voulue, par exemple Impression écran.
  4. NVDA confirme, par exemple « impression écran est maintenant la touche Applications. Avec Maj, elle ouvre le menu étendu. » C'est fini : la touche fonctionne tout de suite, dans tous vos programmes.

Échap annule l'attente. Les touches qui servent à écrire ou à se déplacer, utilisées seules (une lettre, un chiffre, Entrée, Tab, Espace, les flèches…), sont refusées : NVDA vous demande alors d'en choisir une autre.

Pour la touche Applications, seule une touche seule est acceptée, sans Ctrl, Alt, Maj ni NVDA : c'est ce qui permet à Maj avec cette touche d'ouvrir le menu étendu. Les touches seules qui conviennent le mieux sont AltGr (Alt droite), Ctrl droite, Impression écran, Pause et Arrêt défilement.

Avec AltGr ou Ctrl droite, la touche Applications fonctionne quand vous appuyez puis relâchez la touche sans rien d'autre. Utilisée avec une autre touche, elle garde son rôle habituel : AltGr+2 donne toujours @, par exemple. Si vous la gardez enfoncée plus d'une seconde, rien ne se passe. Pour les clics, vous pouvez aussi choisir une combinaison, par exemple Ctrl+Alt+K.

Si la touche sert déjà à une autre commande de NVDA ou d'une extension, NVDA vous le dit et vous demande si vous voulez l'utiliser quand même. Chaque action a une seule touche : en assigner une nouvelle remplace l'ancienne.

Retirer une touche

Choisissez l'action, puis appuyez sur Supprimer, ou sur le bouton « Retirer la touche ».

Le son des clics

La case « Jouer un son à chaque clic » fait entendre un petit clic de confirmation. Elle est cochée par défaut.

La langue du clavier

La liste « Langue du clavier » commence par votre clavier, par exemple « Votre clavier : Français (Canada) », puis donne toutes les dispositions de clavier de Windows, plus de deux cents, par ordre alphabétique. Tapez la première lettre d'un nom pour y aller directement. La disposition en cours est suivie de « (en cours) ».

Entrée sur une langue l'active aussitôt dans tous vos programmes, et NVDA confirme, par exemple « Clavier : Anglais (États-Unis) ». Tout fonctionne exactement comme si vous l'aviez ajoutée dans les paramètres de Windows, les combinaisons comme Ctrl+Z et les touches mortes comprises, parce que c'est vraiment la disposition de Windows qui est utilisée. Rien n'est téléchargé.

Entrée sur « Votre clavier » vous ramène à votre clavier. Les langues que l'extension avait ajoutées sont alors retirées de Windows. Celles que vous aviez vous-même ajoutées dans les paramètres de Windows restent.

L'action « Changer de clavier », dans la liste des actions, passe d'une seule touche de votre clavier à la dernière langue choisie, et inversement. Donnez-lui une touche pour aller et venir sans ouvrir la fenêtre.

Échap ou le bouton « Fermer » ferment la fenêtre. Fermez-la, puis utilisez vos touches et votre clavier dans vos programmes.

Bon à savoir

  • Les touches assignées sont enregistrées dans les gestes de commandes de NVDA. Vous les retrouvez aussi dans le menu NVDA, Préférences, Gestes de commandes, rubrique « KeyboardAccess ».
  • Si vous assignez à un clic une combinaison avec Ctrl, Alt ou Maj, l'extension attend que vous relâchiez ces touches avant de cliquer.
  • La touche Applications et Maj avec elle apparaissent aussi séparément dans les Gestes de commandes de NVDA, sauf AltGr et Ctrl droite, que NVDA ne sait pas assigner seules : l'extension les surveille elle-même.
  • Si un logiciel comme SharpKeys a déjà remplacé une touche dans Windows, retirez d'abord ce remplacement.
  • Pour cliquer, l'extension place le pointeur de la souris sur l'élément sélectionné. Si l'élément n'est pas visible à l'écran, NVDA le dit et ne clique pas.
  • Dans la plupart des programmes, Maj+F10 ouvre aussi le menu contextuel, sans extension.
  • Votre clavier est celui que vous utilisiez la première fois que vous avez changé de langue avec l'extension.
  • Pendant qu'une langue ajoutée par l'extension est active, elle apparaît aussi dans le sélecteur de langue de Windows (Windows+Espace). Elle en disparaît quand vous revenez à votre clavier.
  • Le changement de langue suit le réglage de Windows : par défaut, la même langue de clavier vaut pour tous les programmes.

Réglages

Dans le menu NVDA, Préférences, Paramètres, catégorie « KeyboardAccess » :

  • Jouer un son à chaque clic : cochée par défaut.
  • Vérifier automatiquement les mises à jour au démarrage de NVDA : cochée par défaut.
  • Vérifier les mises à jour maintenant : lance la vérification tout de suite.

Mises à jour

KeyboardAccess ne passe pas par l'Add-on Store de NVDA. L'extension vérifie elle-même, peu après le démarrage de NVDA, si une nouvelle version est publiée, et vous propose de l'installer. Lorsque plusieurs extensions ReaperAccessible se mettent à jour ensemble, leurs fenêtres s'ouvrent l'une après l'autre et NVDA ne demande à redémarrer qu'une seule fois.

Dans l'Add-on Store, l'extension apparaît avec le canal « Externe ». C'est normal pour une extension installée en dehors du Store.

Confidentialité

L'extension ne contacte Internet que pour vérifier les mises à jour, auprès de GitHub.
