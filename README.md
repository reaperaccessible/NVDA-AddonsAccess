# NVDA-AddonsAccess

Accessible add-ons for the NVDA screen reader, by ReaperAccessible.
Extensions accessibles pour le lecteur d'écran NVDA, par ReaperAccessible.

## Add-ons

- **LocalTranslateAccess** — translates what NVDA says, on your own computer. French and English are included; other languages are downloaded as language packs. NVDA+Shift+T translates the selected text; NVDA+Ctrl+Shift+T opens the translation menu.
- **ToneTunerAccess** — reference tones to tune a guitar by ear: each string, all the strings or a chord, once or in a loop. NVDA+Ctrl+Shift+A opens the tuner. Based on Reference Tone Tuner by Leandro Souza (GPL v2).
- **ResourceMonitorAccess** — announces the state of the computer: processor, applications using the most, memory, drives, network connection, Internet speed test, Wi-Fi, battery, Windows version, time since Windows started and NVIDIA graphics card; reports Wi-Fi connections and disconnections. NVDA+Ctrl+Shift+M opens the resource window. Based on Resource Monitor by Alex Hall, Joseph Lee, Kefas Lungu and other NVDA contributors (GPL v2).
- **KeyboardAccess** — keyboard tools: gives back the Applications key to keyboards that do not have one, clicks the selected item, and changes the keyboard language among all those of Windows without adding them in its settings. NVDA+Ctrl+Shift+K opens the keyboard window. Based on Remap Applications Key by Rui Fontes, Ângelo Abrantes and Héctor J. Benítez Corredera (GPL v2).
- **SpeechHistoryAccess** — review and copy NVDA's speech history. Interface in French when NVDA is in French, in English otherwise. Based on Speech History by Tyler Spivey and James Scholes (GPL v2).

## Installation

Download the `.nvda-addon` file from the [Releases](https://github.com/reaperaccessible/NVDA-AddonsAccess/releases) page and open it; NVDA offers to install it.

Each add-on then checks this repository for new versions when NVDA starts, and offers to install them.

Téléchargez le fichier `.nvda-addon` depuis la page [Releases](https://github.com/reaperaccessible/NVDA-AddonsAccess/releases) et ouvrez-le ; NVDA propose de l'installer. Chaque extension vérifie ensuite ce dépôt au démarrage de NVDA et propose les nouvelles versions.
