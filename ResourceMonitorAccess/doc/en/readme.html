ResourceMonitorAccess

ResourceMonitorAccess tells you the state of your computer: the processor load, the memory used, the space on the drives, the Wi-Fi connection, the Windows version, the time since Windows started and the graphics card. It also reports Wi-Fi connections and disconnections.

The add-on is displayed in French when NVDA is in French, and in English in every other language. Sizes are written in your language: "12.5 GB" in English, "12,5 Go" in French.

The shortcut and the resource window

NVDA+Ctrl+Shift+M opens the resource window. It holds a list: choose a piece of information with the arrow keys, or by typing its first letter, then press Enter to hear it. The window stays open: you can listen to another one right away, or listen to the same one again to follow how it changes. Escape or the "Close" button close the window.

  • Summary: the memory used and the processor load.
  • Processor: the average load, then that of each core.
  • Applications using the most: the 5 applications using the most processor, with the memory of each, for example "reaper: processor 23%, memory 2.1 GB". When nothing is working, these are the ones using the most memory. The windows and tabs of one application are counted together.
  • Memory: the physical memory, then the virtual memory, used and total.
  • Drives: the space used on each drive, including removable and network drives.
  • Network connection: whether the computer is connected by cable or by Wi-Fi, whether the Internet is reachable, and the current download and upload speed.
  • Internet speed test: measures the top speed of your Internet connection, for download and upload, and the response time. The test takes 15 seconds at most, less on a fast connection; NVDA says that it is starting, then gives the result, for example "Download: 245 megabits per second. Upload: 38 megabits per second. Response time: 13 milliseconds." You can keep using the computer meanwhile.
  • Wi-Fi: the network you are connected to, the signal strength and the type of security.
  • Battery: on a laptop only, the battery level, whether the computer is plugged in and, if not, the time left.
  • Windows version: the version, the processor architecture and the build number.
  • Time since Windows started: for example "Windows started 2 days, 3 hours, 12 minutes ago".
  • Graphics card: its use and its temperature.
  • Graphics card memory: the memory used on the graphics card.
  • Copy the last information: puts the last information announced on the clipboard. Ctrl+C does the same from anywhere in the window.
  • Configuration: closes the window and opens the add-on's settings.

The graphics card is only read when it is an NVIDIA card. It is not read on secure screens, such as the Windows sign-in screen.

Assigning your own shortcuts

Each piece of information in the window also exists as a separate command, with no key assigned by default. Open the NVDA menu, Preferences, Input gestures, "ResourceMonitorAccess" category, select the command you want, choose "Add", then press the shortcut you wish.

With such a command, one press announces the information, and two quick presses copy it to the clipboard. For the speed test, which is long, two presses do not run it again: copy its result with "Copy the last information". These commands also work in speak on demand mode.

Wi-Fi connections

When your computer connects to a Wi-Fi network or disconnects from it, or when a Wi-Fi adapter is turned on or off, NVDA says so and plays a sound. You can choose this behaviour in the settings.

Settings

Open the NVDA menu, Preferences, Settings, then the "ResourceMonitorAccess" category, or choose "Configuration" in the resource window.

  • Wi-Fi connections and disconnections: say nothing, announce them, play a sound, or announce them and play a sound. By default, announce them and play a sound.
  • Temperature of the graphics card in: degrees Celsius or degrees Fahrenheit. By default, Celsius.
  • Check for updates automatically when NVDA starts: checked by default.
  • Check for updates now: starts the check right away.

Good to know

  • The processor load is given per logical processor. On a processor with hyper-threading, twice as many "cores" are therefore announced as there are physical cores.
  • During heavy drive activity, or if a network drive is slow to answer, announcing the drives can take a few seconds. NVDA stays usable meanwhile.
  • To know whether the Internet is reachable, the add-on asks Windows what it already knows: it does not contact any server.
  • Sizes are counted as in Windows File Explorer.
  • If the original Resource Monitor add-on is also installed, uninstall it: both would announce each Wi-Fi connection.

Updates

ResourceMonitorAccess does not go through NVDA's Add-on Store. The add-on checks by itself, shortly after NVDA starts, whether a new version has been published, and offers to install it. When several ReaperAccessible add-ons are updated together, their windows open one after the other and NVDA asks to restart only once.

In the Add-on Store, the add-on is listed with the "External" channel. This is normal for an add-on installed from outside the Store.

Privacy

The information stays on your computer. The add-on only contacts the Internet to check for updates, with GitHub, and for the speed test, with Cloudflare's speed test service, only when you ask for it. To spare limited connections, a test exchanges about 225 MB at most. If you run many tests in a row, the service may refuse for a while: NVDA then tells you how long to wait.
