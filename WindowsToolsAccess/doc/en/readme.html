WindowsToolsAccess

WindowsToolsAccess brings Windows maintenance tools together in one window: turn the Internet or Bluetooth off, remove a USB drive, clean unneeded files, choose the programs started with Windows, manage services, open Windows panels, repair Windows with DISM or SFC, and much more.

The add-on speaks French when NVDA is in French, and English in every other language.

The window

NVDA+Ctrl+Shift+W opens the window, also found in the NVDA menu, Tools. It has six tabs:

  • The window opens on the tabs: Left and Right arrows go to the previous or next tab, and Tab goes into the tab, on its list. Shift+Tab comes back.
  • Ctrl+Tab and Ctrl+Shift+Tab go to the next or previous tab from anywhere in the window.
  • Ctrl+1 to Ctrl+6 go straight to a tab.
  • In a list, Enter runs the selected tool.
  • Escape closes the window. It opens again on the last tab used.

Long tools, such as DISM, SFC, Defender or cleaning, work in the background: NVDA tells you when they start and when they end, and the window stays usable meanwhile. Many tools first ask for Windows' permission: accept it to go on.

1. Quick tools

  • System Tray: closes the window and takes you to Windows' notification area, with the hidden icons shown.
  • Disconnect Internet or Connect Internet: turns the network adapter in use off or on. The name follows the state of the connection.
  • Bluetooth on or off.
  • Copy the Wi-Fi password: copies the password of the Wi-Fi network in use, to give it to someone.
  • Safely Remove USB: with one drive, it is removed at once; with several, you choose which one.
  • Kill Not Responding Apps: opens the list of frozen programs, to close them.
  • Restart Windows Explorer: useful when the taskbar or the desktop stop responding.
  • Empty Recycle Bin.

2. Cleaning

  • Clean Temp: removes temporary files. Files in use or changed in the last day are kept, so programs at work are not disturbed.
  • Clean Windows Run History.
  • Disk Cleanup: opens Windows' tool, to choose yourself what to clean.
  • Optimize and defragment drive: opens Windows' tool.

3. Startup

The list of programs started with Windows, for example "Discord, Enabled, Registry". Enter disables or enables the selected program; NVDA tells the result. A disabled program is set aside, not deleted.

4. Services

The list of Windows services that can be stopped to lighten the computer, each with its startup type, its state, and Safe or Caution. The list loads the first time you open the tab.

  • Enter disables the selected service, or enables it if it is disabled. For a service marked Caution, NVDA first tells what it is for and asks you to confirm.
  • Details: the name, state and description of the service.
  • Disable all safe services: only those marked Safe, after a confirmation.
  • Enable all: each service gets back the startup type it had before.
  • Refresh loads the list again.

5. Windows panels

Opens directly: Control Panel, Programs and Features, Folder Options, the Registry Editor, Windows Security (Defender), Microsoft's Malicious Software Removal Tool, and Windows' Services window.

6. Advanced

  • Disable or Enable User Account Control: the change counts after Windows restarts.
  • Disable or Enable Search Web Results: the Start menu search looks only in the computer, or on the Internet too. Explorer restarts to apply it.
  • Restart to BIOS/UEFI Settings: after a confirmation, the computer restarts at once into its startup settings. Save your work first.
  • Run DISM: repairs the Windows image. It can take 15 to 30 minutes.
  • Run SFC Scannow: checks and repairs Windows files.
  • Run Chkdsk on C:: as the system drive is in use, the check is usually set for the next restart.
  • Check Disk Status: the health of each disk.
  • Power Diagnostic (Battery Report).
  • Run Windows Defender Full Scan, and Windows Defender Full Scan Low, which slows the computer down less. It can take a long time.
  • Backup Open With and Restore Open With: keeps the program chosen to open each type of file, and puts it back. Restoring only works on the same Windows installation and user account.
  • Environment Variables: opens Windows' window where the folder paths Windows gives to programs are set, such as Path. A wrong change can stop some programs from starting.

When a long tool ends, NVDA says so and opens its report in Notepad (or the browser for the battery report).

Commands and their keys

Only opening the window has a key by default. Each tool is also a command, without a key, as are "Startup Manager" and "Manage Services", which open the window on their tab.

To give them a key, choose the "Assign keys to the commands" button at the bottom of each tab (Alt+K). Choose the command, press Enter, then the key you want: it is assigned at once. If the key is already used, NVDA asks you first. Delete removes the key of a command. You also find them in the NVDA menu, Preferences, Input gestures, category "WindowsToolsAccess".

Settings

In the NVDA menu, Preferences, Settings, category "WindowsToolsAccess":

  • Check for updates automatically when NVDA starts: checked by default.
  • Check for updates now: checks at once.

Updates

WindowsToolsAccess does not go through NVDA's Add-on Store. The add-on checks itself, shortly after NVDA starts, whether a new version is published, and offers to install it. When several ReaperAccessible add-ons update together, their windows open one after the other and NVDA asks to restart only once.

In the Add-on Store, the add-on shows the "External" channel. This is normal for an add-on installed outside the Store.

Privacy

The add-on checks for updates with GitHub. To know whether the Internet is connected, it sends a simple ping to the address 8.8.8.8 when the window opens. Nothing else leaves the computer. Reports and backups stay in NVDA's configuration folder, under "WindowsToolsAccess".
