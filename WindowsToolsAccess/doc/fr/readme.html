WindowsToolsAccess

WindowsToolsAccess réunit les outils d'entretien de Windows dans une seule fenêtre : couper Internet ou le Bluetooth, retirer une clé USB, nettoyer les fichiers inutiles, choisir les programmes lancés avec Windows, gérer les services, ouvrir les panneaux de Windows, réparer Windows avec DISM ou SFC, et bien d'autres.

L'extension s'affiche en français lorsque NVDA est en français, et en anglais dans toutes les autres langues.

La fenêtre

NVDA+Ctrl+Maj+W ouvre la fenêtre, que l'on trouve aussi dans le menu NVDA, Outils. Elle a six onglets :

  • La fenêtre s'ouvre sur les onglets : les flèches gauche et droite passent à l'onglet précédent ou suivant, et Tab entre dans l'onglet, sur sa liste. Maj+Tab revient aux onglets.
  • Ctrl+Tab et Ctrl+Maj+Tab passent à l'onglet suivant ou précédent depuis n'importe où dans la fenêtre.
  • Ctrl+1 à Ctrl+6 vont directement à un onglet.
  • Dans une liste, Entrée lance l'outil choisi.
  • Échap ferme la fenêtre. Elle se rouvre sur le dernier onglet utilisé.

Les outils longs, comme DISM, SFC, Defender ou le nettoyage, travaillent en arrière-plan : NVDA annonce le début et la fin, et la fenêtre reste utilisable pendant ce temps. Beaucoup d'outils demandent d'abord l'autorisation de Windows : acceptez-la pour continuer.

1. Outils rapides

  • Zone de notification : ferme la fenêtre et vous place dans la zone de notification de Windows, avec les icônes cachées dépliées.
  • Déconnecter Internet ou Connecter Internet : coupe ou rétablit la carte réseau en usage. Le nom suit l'état de la connexion.
  • Bluetooth : l'allume ou l'éteint.
  • Copier le mot de passe Wi-Fi : copie le mot de passe du réseau Wi-Fi en usage, pour le donner à quelqu'un.
  • Retirer la clé USB en toute sécurité : s'il n'y a qu'une clé, elle est retirée aussitôt ; s'il y en a plusieurs, vous choisissez laquelle.
  • Fermer les applications qui ne répondent pas : ouvre la liste des programmes bloqués, pour les fermer.
  • Redémarrer l'Explorateur Windows : utile quand la barre des tâches ou le bureau ne répondent plus.
  • Vider la corbeille.

2. Nettoyage

  • Nettoyer les fichiers temporaires : supprime les fichiers temporaires. Les fichiers ouverts ou modifiés depuis moins d'un jour sont gardés, pour ne pas déranger les programmes au travail.
  • Effacer l'historique de la commande Exécuter.
  • Nettoyage de disque : ouvre l'outil de Windows, pour choisir vous-même quoi nettoyer.
  • Optimiser les lecteurs : ouvre l'outil de Windows qui optimise et défragmente les disques.

3. Démarrage

La liste des programmes lancés avec Windows, par exemple « Discord, Activé, Registre ». Entrée désactive ou réactive le programme choisi ; NVDA annonce le résultat. Un programme désactivé est mis de côté, pas supprimé.

4. Services

La liste des services de Windows que l'on peut sans risque arrêter pour alléger l'ordinateur, chacun avec son type de démarrage, son état, et la mention Sûr ou Prudence. La liste se charge la première fois que vous ouvrez l'onglet.

  • Entrée désactive le service choisi, ou le réactive s'il est désactivé. Pour un service marqué Prudence, NVDA vous dit d'abord à quoi il sert et vous demande de confirmer.
  • Détails : le nom, l'état et la description du service.
  • Désactiver tous les services sûrs : seulement ceux marqués Sûr, après confirmation.
  • Tout réactiver : chaque service retrouve le démarrage qu'il avait avant.
  • Actualiser recharge la liste.

5. Fenêtres de Windows

Ouvre directement : le Panneau de configuration, Programmes et fonctionnalités, les Options des dossiers, l'Éditeur du Registre, la Sécurité Windows (Defender), l'Outil de suppression de logiciels malveillants de Microsoft, et la fenêtre Services de Windows.

6. Avancé

  • Désactiver ou Activer le contrôle de compte d'utilisateur : le changement compte après le redémarrage de Windows.
  • Désactiver ou Activer les résultats web de la recherche : la recherche du menu Démarrer cherche seulement dans l'ordinateur, ou aussi sur Internet. L'Explorateur redémarre pour l'appliquer.
  • Redémarrer dans le BIOS ou l'UEFI : après une confirmation, l'ordinateur redémarre aussitôt dans ses réglages de démarrage. Enregistrez votre travail avant.
  • DISM : répare l'image de Windows. Cela peut durer de 15 à 30 minutes.
  • SFC : vérifie et répare les fichiers de Windows.
  • Chkdsk sur C: : le disque système étant en usage, la vérification est en général prévue pour le prochain redémarrage.
  • État des disques : la santé de chaque disque.
  • Rapport de batterie.
  • Analyse complète de Windows Defender, et la même à basse priorité, qui ralentit moins l'ordinateur. Elle peut durer longtemps.
  • Sauvegarder Ouvrir avec et Restaurer Ouvrir avec : garde le programme choisi pour ouvrir chaque type de fichier, et le remet. La restauration ne fonctionne que sur la même installation de Windows et le même compte.
  • Variables d'environnement : ouvre la fenêtre de Windows où l'on règle les chemins de dossiers que Windows donne aux programmes, comme Path. Une mauvaise modification peut empêcher certains programmes de démarrer.

Quand un outil long se termine, NVDA l'annonce et ouvre son rapport dans le Bloc-notes (ou le navigateur pour le rapport de batterie).

Les commandes et leurs touches

Seule l'ouverture de la fenêtre a une touche par défaut. Chaque outil existe aussi comme commande, sans touche, ainsi que « Gestionnaire de démarrage » et « Gérer les services », qui ouvrent la fenêtre sur leur onglet.

Pour leur donner une touche, choisissez le bouton « Assigner des touches aux commandes », en bas de chaque onglet (Alt+T). Choisissez la commande, appuyez sur Entrée, puis sur la touche voulue : elle est assignée aussitôt. Si la touche sert déjà à autre chose, NVDA vous le demande avant. Supprimer retire la touche d'une commande. Vous les retrouvez aussi dans le menu NVDA, Préférences, Gestes de commandes, rubrique « WindowsToolsAccess ».

Réglages

Dans le menu NVDA, Préférences, Paramètres, catégorie « WindowsToolsAccess » :

  • Vérifier automatiquement les mises à jour au démarrage de NVDA : cochée par défaut.
  • Vérifier les mises à jour maintenant : lance la vérification tout de suite.

Mises à jour

WindowsToolsAccess ne passe pas par l'Add-on Store de NVDA. L'extension vérifie elle-même, peu après le démarrage de NVDA, si une nouvelle version est publiée, et vous propose de l'installer. Lorsque plusieurs extensions ReaperAccessible se mettent à jour ensemble, leurs fenêtres s'ouvrent l'une après l'autre et NVDA ne demande à redémarrer qu'une seule fois.

Dans l'Add-on Store, l'extension apparaît avec le canal « Externe ». C'est normal pour une extension installée en dehors du Store.

Confidentialité

L'extension vérifie les mises à jour auprès de GitHub. Pour savoir si Internet est connecté, elle envoie un simple ping à l'adresse 8.8.8.8 quand la fenêtre s'ouvre. Rien d'autre ne quitte l'ordinateur. Les rapports et sauvegardes restent dans le dossier de configuration de NVDA, sous « WindowsToolsAccess ».
