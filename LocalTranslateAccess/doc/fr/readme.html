LocalTranslateAccess

LocalTranslateAccess traduit ce que NVDA annonce. La traduction est calculée sur votre ordinateur : aucun texte n'est envoyé sur Internet.

Vous pouvez traduire en continu tout ce que NVDA dit dans une application ou dans toutes, ou traduire ponctuellement un texte sélectionné, le presse-papiers ou la dernière annonce.

Le français et l'anglais sont inclus et fonctionnent dès l'installation. Les autres langues s'ajoutent sous forme de packs de langues, téléchargés à votre demande.

L'extension s'affiche en français lorsque NVDA est en français, et en anglais dans toutes les autres langues.

Le raccourci et le menu de traduction

L'extension n'a qu'un seul raccourci : NVDA+Ctrl+Maj+T. Il ouvre le menu de traduction. Parcourez-le avec les flèches et validez avec Entrée, ou appuyez directement sur la lettre indiquée.

  • Traduction pour cette application (A) : activer ou désactiver la traduction de tout ce que NVDA annonce dans l'application en cours. L'entrée est cochée lorsque la traduction est active.
  • Traduction globale (G) : activer ou désactiver la traduction dans toutes les applications. L'entrée est cochée lorsque la traduction est active.
  • Traduire la sélection (S) : traduire le texte sélectionné.
  • Traduire le presse-papiers (P) : traduire le texte que vous avez copié.
  • Traduire la dernière annonce (D) : traduire ce que NVDA vient de dire.
  • Copier la dernière traduction (C) : placer la dernière traduction dans le presse-papiers.
  • Inverser les langues (I) : traduire dans l'autre sens.
  • Annoncer les langues (L) : entendre la langue source et la langue cible actuelles.
  • Configuration de la traduction (F) : ouvrir les réglages de l'extension.

Attribuer vos propres raccourcis

Chaque action du menu existe aussi comme commande séparée, sans touche attribuée par défaut. Si vous utilisez souvent une action, vous pouvez lui donner un raccourci direct et vous passer du menu.

  1. Ouvrez le menu NVDA, Préférences, Gestes de commandes.
  2. Développez la rubrique « LocalTranslateAccess ».
  3. Sélectionnez la commande voulue, choisissez « Ajouter », puis appuyez sur le raccourci souhaité.

Les commandes disponibles sont : ouvrir le menu de traduction, activer ou désactiver la traduction pour l'application en cours, activer ou désactiver la traduction globale, traduire le texte sélectionné, traduire le presse-papiers, traduire la dernière annonce, copier la dernière traduction, inverser les langues, annoncer les langues, et ouvrir la configuration.

C'est aussi dans cette rubrique que vous pouvez changer le raccourci du menu.

Traduire en continu

Choisissez « Traduction pour cette application » lorsqu'un seul programme est dans une autre langue, par exemple un jeu ou un logiciel non traduit. Les autres applications ne sont pas touchées, et chaque application garde ses propres langues.

Choisissez « Traduction globale » pour traduire partout avec un seul réglage de langues.

Un bip et une annonce confirment l'activation. Refaites le même choix dans le menu pour désactiver la traduction.

Première activation

La première fois que vous activez la traduction pour une application, ou en mode global, un assistant s'ouvre. Tout se fait dans la même fenêtre.

  1. Choisissez une ou plusieurs langues sources avec les flèches et Espace. La langue détectée dans l'application est présélectionnée lorsqu'elle est connue.
  2. Choisissez la langue cible, puis « Ajouter ». Vous pouvez ajouter plusieurs paires de langues.
  3. Choisissez un modèle dans la liste. Ceux qui sont déjà prêts portent la mention « installé ».
  4. Si le bouton indique « Appliquer », validez : la traduction s'active. S'il indique « Télécharger », validez pour télécharger le pack de langues ; le bouton affiche la progression, puis devient « Appliquer ».

Annuler ferme l'assistant sans activer la traduction. Ce qui a déjà été téléchargé reste disponible.

Traduire un texte à la demande

Les entrées « Traduire la sélection », « Traduire le presse-papiers » et « Traduire la dernière annonce » fonctionnent même si la traduction en continu est désactivée.

  • Une traduction courte est annoncée.
  • Une traduction longue, ou sur plusieurs lignes, s'ouvre dans une fenêtre que vous lisez avec les flèches.
  • Si le texte est déjà dans la langue cible, il est traduit dans l'autre sens. Un texte français sera par exemple traduit en anglais.
  • Si la langue du texte n'est pas installée, une fenêtre vous le dit et vous propose de l'installer. Si vous répondez Oui, le téléchargement s'ouvre avec cette langue déjà choisie ; une fois le pack installé, votre texte est traduit aussitôt.
  • N'importe quel modèle installé capable de traduire ces langues est utilisé, même s'il n'est pas celui choisi dans les réglages.

La langue du texte est toujours détectée automatiquement, quel que soit votre réglage de langue source. Le texte est traduit vers la langue cible configurée pour l'application en cours, ou vers la langue cible globale si l'application n'a pas de réglage propre. Pour un texte très court, la détection n'est pas fiable : votre langue source configurée est alors utilisée.

Réglages

Ouvrez le menu NVDA, Préférences, Paramètres, puis la catégorie « LocalTranslateAccess ». Vous y arrivez aussi par « Configuration de la traduction » dans le menu de traduction.

La catégorie contient quatre onglets, puis les réglages de mise à jour. La traduction en continu est suspendue pendant que cette catégorie est ouverte.

Onglet Langues

  • Langue source pour la traduction globale : « Détection automatique » ou une langue précise.
  • Langue cible pour la traduction globale : la langue dans laquelle NVDA annonce les traductions.
  • Modèle pour la traduction globale : le modèle utilisé pour ces langues.
  • Applications avec une langue source configurée : la liste des applications que vous avez déjà réglées. Sélectionnez-en une pour modifier les trois réglages suivants.
  • Langue source, langue cible et modèle pour cette application : les mêmes choix, propres à l'application sélectionnée.
  • Utiliser la carte graphique pour accélérer la traduction : cette case apparaît seulement pour les modèles et les ordinateurs qui le permettent.

Le bouton sous les onglets indique « Appliquer » quand tout est prêt, et « Télécharger » quand le modèle choisi n'est pas encore installé. Le bouton OK des Paramètres de NVDA enregistre aussi vos choix de langues, mais ne lance jamais de téléchargement.

La première langue cible proposée est celle de la voix de NVDA. En détection automatique, une langue détectée pour laquelle aucun modèle n'est installé n'est pas traduite : le texte d'origine est annoncé.

Onglet Modèles installés

Cet onglet liste les modèles présents sur votre ordinateur, avec leur taille. C'est ici que vous gérez vos langues.

  • Ajouter une langue : ouvre la fenêtre de téléchargement. Choisissez une ou plusieurs langues sources, la langue cible, puis « Ajouter » ; choisissez un modèle et validez « Télécharger ». Vos réglages de traduction ne sont pas modifiés : la langue est simplement disponible.
  • Supprimer le modèle sélectionné : libère de la place sur votre disque.
  • Actualiser le catalogue des modèles : affiche les packs de langues ajoutés depuis l'installation de l'extension.

Onglet Cache de traduction

L'extension garde en mémoire les traductions déjà faites, pour les redonner immédiatement. Dans cet onglet, vous pouvez rechercher une traduction, la corriger, et exporter ou importer un cache pour le partager.

Onglet Performances

Cet onglet indique le temps de chargement des modèles et le temps moyen de traduction par paire de langues. Un bouton efface ces mesures.

Mises à jour

  • Vérifier automatiquement les mises à jour au démarrage de NVDA : cochée par défaut.
  • Vérifier les mises à jour maintenant : ce bouton lance la vérification tout de suite.

Langues et packs de langues

Un pack de langues est téléchargé une seule fois, puis utilisé sans connexion. Il existe deux sortes de modèles.

  • Firefox / Bergamot : un modèle par paire de langues, rapide, d'environ 25 à 50 Mo. C'est le modèle inclus pour le français et l'anglais. Pour deux langues autres que l'anglais, la traduction passe par l'anglais et demande donc deux packs.
  • Modèles multilingues (NLLB-200, SMaLL-100, M2M-100) : un seul téléchargement de 350 à 650 Mo couvre de nombreuses langues, y compris certaines que Bergamot ne propose pas. Ils sont plus lents.

Mises à jour de l'extension

LocalTranslateAccess ne passe pas par l'Add-on Store de NVDA. L'extension vérifie elle-même, peu après le démarrage de NVDA, si une nouvelle version est publiée. Si c'est le cas, une fenêtre vous propose de l'installer. Lorsque plusieurs extensions ReaperAccessible se mettent à jour ensemble, leurs fenêtres s'ouvrent l'une après l'autre et NVDA ne demande à redémarrer qu'une seule fois, à la fin.

Vos langues, vos modèles et votre cache sont conservés lors d'une mise à jour.

Dans l'Add-on Store, l'extension apparaît avec le canal « Externe ». C'est normal pour une extension installée en dehors du Store.

Confidentialité

  • Les textes à traduire et leurs traductions restent sur votre ordinateur.
  • L'extension contacte Internet dans deux cas seulement : pour télécharger un pack de langues ou actualiser le catalogue, à votre demande, et pour vérifier les mises à jour. Ces échanges se font avec GitHub.
  • Les mesures de performances ne contiennent que des durées, jamais de texte.
