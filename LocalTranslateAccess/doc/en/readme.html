LocalTranslateAccess

LocalTranslateAccess translates what NVDA says. The translation is computed on your computer: no text is sent over the Internet.

You can translate everything NVDA says in one application or in all of them, continuously, or translate a selected text, the clipboard or the last announcement on request.

French and English are included and work as soon as the add-on is installed. Other languages are added as language packs, downloaded when you ask for them.

The add-on is displayed in French when NVDA is in French, and in English in every other language.

The shortcut and the translation menu

The add-on has a single shortcut: NVDA+Ctrl+Shift+T. It opens the translation menu. Browse it with the arrow keys and press Enter, or press the letter given below.

  • Translation for this application (T): turn the translation of everything NVDA says in the current application on or off. The item is checked while translation is on.
  • Global translation (G): turn translation on or off in every application. The item is checked while translation is on.
  • Translate the selection (S): translate the selected text.
  • Translate the clipboard (P): translate the text you copied.
  • Translate the last announcement (L): translate what NVDA has just said.
  • Copy the last translation (C): put the last translation on the clipboard.
  • Swap the languages (W): translate the other way round.
  • Announce the languages (A): hear the current source and target languages.
  • Translation configuration (F): open the add-on's settings.

Assigning your own shortcuts

Each action of the menu also exists as a separate command, with no key assigned by default. If you use an action often, you can give it a direct shortcut and do without the menu.

  1. Open the NVDA menu, Preferences, Input gestures.
  2. Expand the "LocalTranslateAccess" category.
  3. Select the command you want, choose "Add", then press the shortcut you wish.

The available commands are: open the translation menu, turn translation on or off for the current application, turn global translation on or off, translate the selected text, translate the clipboard, translate the last announcement, copy the last translation, swap the languages, announce the languages, and open the configuration.

This category is also where you can change the shortcut of the menu.

Translating continuously

Choose "Translation for this application" when a single program is in another language, for example a game or software that has not been translated. Other applications are left alone, and each application keeps its own languages.

Choose "Global translation" to translate everywhere with a single language setting.

A beep and an announcement confirm that translation is on. Choose the same item again to turn it off.

First activation

The first time you turn translation on for an application, or globally, a setup window opens. Everything is done in that one window.

  1. Choose one or more source languages with the arrow keys and Space. The language detected in the application is preselected when it is known.
  2. Choose the target language, then "Add". You can add several language pairs.
  3. Choose a model in the list. Those that are ready are marked "installed".
  4. If the button reads "Apply", press it: translation turns on. If it reads "Download", press it to download the language pack; the button shows the progress, then becomes "Apply".

Cancel closes the window without turning translation on. Whatever was already downloaded stays available.

Translating a text on request

"Translate the selection", "Translate the clipboard" and "Translate the last announcement" work even when continuous translation is off.

  • A short translation is spoken.
  • A long translation, or one with several lines, opens in a window that you read with the arrow keys.
  • If the text is already in the target language, it is translated the other way round. A French text, for example, is translated into English.
  • If the language of the text is not installed, a window says so, gives the size of the download and asks whether you want to download it. If you answer Yes, the language is downloaded, then your text is translated at once.

The language of the text is always detected automatically, whatever your source language setting. The text is translated into the target language configured for the current application, or into the global target language if the application has no setting of its own. For a very short text, detection is not reliable: your configured source language is used instead.

Settings

Open the NVDA menu, Preferences, Settings, then the "LocalTranslateAccess" category. "Translation configuration" in the translation menu takes you there too.

The category holds four tabs, followed by the update settings. Continuous translation is paused while this category is open.

Languages tab

  • Source language for global translation: "Automatic detection" or a specific language.
  • Target language for global translation: the language in which NVDA speaks the translations.
  • Model for global translation: the model used for these languages.
  • Applications with a configured source language: the applications you have already set up. Select one to change the next three settings.
  • Source language, target language and model for this application: the same choices, for the selected application only.
  • Use the graphics card to speed up translation: this box only appears for the models and computers that allow it.

The button under the tabs reads "Apply" when everything is ready, and "Download" when the chosen model is not installed yet. The OK button of NVDA's Settings dialog also saves your language choices, but never starts a download.

The first target language offered is that of NVDA's voice. With automatic detection, a detected language for which no model is installed is not translated: the original text is spoken.

Installed models tab

This tab lists the models on your computer, with their size. This is where you manage your languages.

  • Add a language: opens the list of available languages, with the size of each. Tick the ones you want with Space, then press "Download". Your translation settings are not changed: the languages are simply available.
  • Remove the selected model: frees some space on your disk.
  • Refresh the model catalogue: shows the language packs added since you installed the add-on.

Translation cache tab

The add-on remembers the translations it has already made, so that it can give them back at once. In this tab you can search for a translation, correct it, and export or import a cache to share it.

Performance tab

This tab shows how long the models take to load and the average translation time for each language pair. A button clears these measurements.

Updates

  • Check for updates automatically when NVDA starts: checked by default.
  • Check for updates now: this button starts the check right away.

Languages and language packs

A language pack is downloaded once, then used without a connection. There are two kinds of models.

  • Firefox / Bergamot: one model per language pair, fast, about 25 to 50 MB. This is the model included for French and English. Between two languages other than English, the translation goes through English and therefore needs two packs.
  • Multilingual models (NLLB-200, SMaLL-100, M2M-100): a single download of 350 to 650 MB covers many languages, including some that Bergamot does not offer. They are slower.

Updates of the add-on

LocalTranslateAccess does not go through NVDA's Add-on Store. The add-on checks by itself, shortly after NVDA starts, whether a new version has been published. If so, a window offers to install it. When several ReaperAccessible add-ons are updated together, their windows open one after the other and NVDA asks to restart only once, at the end.

Your languages, your models and your cache are kept when the add-on is updated.

In the Add-on Store, the add-on is listed with the "External" channel. This is normal for an add-on installed from outside the Store.

Privacy

  • The texts to translate and their translations stay on your computer.
  • The add-on contacts the Internet in two cases only: to download a language pack or refresh the catalogue, when you ask for it, and to check for updates. These exchanges are with GitHub.
  • The performance measurements hold durations only, never any text.
